CVE-2026-132224 — Optimizely Web Experimentation External Control of Critical State Data Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-24

CISA KEV 收錄 Optimizely Web Experimentation 帳號註冊流程中的關鍵狀態資料外部控制漏洞，攻擊者可能冒充既有客戶使用者並修改 Project JavaScript。

成功利用可能使攻擊者控制的 JavaScript 透過 Optimizely 託管資產散布，並在造訪受影響客戶網站的瀏覽器中執行。CISA 要求依廠商指示套用緩解措施並遵循 BOD 26-04。

🔔 建議行動
  • 依廠商指示套用緩解措施，並依 BOD 26-04 評估雲端服務處置；若無緩解措施則考慮停用。
  • 檢視 Project JavaScript 近期是否有未經授權的異動，並依 CISA 鑑識分流要求保存證據。

CVE-2026-131914 — Idunno AntiCsrf Deserialization of Untrusted Data Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-24

CVE-2026-132165 — Drupal Core Remote Code Execution Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-24

CISA KEV 收錄 Drupal Core 漏洞：在特定條件下，未經身分驗證的攻擊者可利用 install.php 嘗試重新安裝 Drupal，進而接管網站或透過安裝程式執行任意程式碼。

CISA 要求依廠商指示套用緩解措施並遵循 BOD 26-04。來源未提供 CVSS 分數。

  • 檢查網站是否有非預期的重新安裝或設定變更跡象。
