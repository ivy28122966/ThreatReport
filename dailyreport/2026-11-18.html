HIGH 漏洞與修補CISA KEVRCE

CVE-2026-115731 — Perforce Puppet Enterprise Deserialization of Untrusted Data Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-17

CISA KEV 收錄 Perforce Puppet Enterprise 的不受信任資料反序列化漏洞。持有任何 CA 簽發 agent 憑證的用戶端，可透過 PUT 請求提交特製 rich-data 型別報告，以服務帳號身分在 Puppet Server 上執行任意程式碼。

若憑證授權中心自動簽發請求且缺乏強驗證，未經驗證的網路攻擊者可取得有效憑證並利用此漏洞。CISA 要求依廠商指示緩解，遵循 BOD 26-04 與「Forensics Triage Requirements」，無法緩解時停用產品。來源未提供 CVSS。

🔔 建議行動
  • 依廠商指示套用緩解或更新，並盤點 Puppet Server 的網際網路暴露情形。
  • 檢查 CA 是否自動簽發憑證，改為需強驗證的簽發流程。
  • 依 CISA 鑑識分流要求檢視 Puppet Server 是否有異常報告提交或執行痕跡。
