CVE-2026-103406 — Hewlett Packard Enterprise (HPE) Juniper Session Smart Conductor and Session Smart Router OS Command Injection Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-25

CISA KEV 收錄 HPE Juniper Session Smart Conductor 與 Session Smart Router 的作業系統命令注入漏洞。依來源描述,遠端攻擊者可透過特製的 salt minion ID,以 root 權限執行任意命令。

來源未提供 CVSS 分數,風險等級依 KEV 收錄及 root 層級遠端命令執行的描述判定為 high。

🔔 建議行動
  • 盤點環境中的 Session Smart Conductor 與 Session Smart Router,並依廠商指示套用緩解措施或更新。
  • 依 CISA BOD 26-04 與 Forensics Triage 要求評估資產的網際網路暴露面,並檢視是否有異常的 minion ID 或 root 命令執行紀錄。
