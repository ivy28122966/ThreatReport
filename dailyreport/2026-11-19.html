Java4Shell Flaw (CVE-2026-114938) Enables Pre-Auth RCE in Jira, Jenkins, Keycloak and More

📰 The Hacker News · The Hacker News · 2026-11-18

研究公司 Calif 本週揭露名為 Java4Shell 的 Java 漏洞（CVE-2026-114938），未經帳號驗證的攻擊者可在 Jira、Jenkins、Keycloak 等六款廣泛使用的應用程式上執行任意程式碼。

來源指出，漏洞存在於 Java 17.0.6 及之後版本，且有漏洞的程式碼僅在支援 AVX-512 VBMI 的 x86-64 Intel 與 AMD 處理器上執行。來源摘要未提供 CVSS 與 KEV 狀態，亦未提及遭利用，無法驗證。依其可造成未驗證遠端程式碼執行，暫列 high。

🔔 建議行動
  • 盤點執行 Java 17.0.6 以上版本的 Jira、Jenkins、Keycloak 等系統，並確認主機 CPU 是否支援 AVX-512 VBMI。
  • 查閱廠商與 Calif 的正式公告，取得修補或緩解措施後依序套用，優先處理對外暴露的系統。
