標題提到攻擊涉及 P2P 存取與驗證弱點，但所提供摘要被截斷，未列出 CVE、CVSS 或具體利用細節。

  • 檢查設備是否有未知帳號或被變更的設定，並重設憑證。
  • 參照 CERT-UA 警示與廠商公告進行韌體更新與網路隔離。

  • 修補前先檢查對外 PHP 服務的異常請求與 Web Shell 跡象。

Hackers Infect 953 Online Stores With Scanner-Evading JavaScript, Mostly on Magento

📰 The Hacker News · The Hacker News · 2026-10-26

荷蘭電商安全公司 Sansec 指出，一個身分不明的攻擊者自 2025 年 7 月起持續活動，已感染 953 個線上商店，多數使用 Magento。

攻擊在商店頁面植入小段程式碼，經由 Magento CMS 區塊載入惡意 JavaScript loader，並具備規避掃描器的設計。摘要未提供 IOC 或 CVE。

🔔 建議行動
  • 檢查 Magento CMS 區塊與頁面範本中是否有未知的 JavaScript 或內嵌載入程式碼。
  • 限制後台帳號權限並啟用 MFA，審視近期後台變更紀錄。
  • 參考 Sansec 報告核對 IOC，並盤點結帳頁面的第三方腳本。

PHP Issues Second Windows Security Update in Five Days to Fix Brotli Code Execution Flaw

📰 The Hacker News · The Hacker News · 2026-10-26

PHP 重新建置 PHP 8.2 至 8.5 的官方 Windows 套件，以修復內含 Brotli 壓縮函式庫的 CVE-2026-111497，該漏洞可能造成記憶體損毀並有機會執行程式碼。

PHP 表示當 cURL 擴充功能自動解壓縮 HTTP 回應時可觸及此漏洞；cURL 預設關閉該功能。來源未提供 CVSS 與 KEV 資訊，故依利用條件限制暫列 medium。

🔔 建議行動
  • 更新至重建後的 PHP Windows 套件（8.2–8.5）。
  • 檢查應用程式是否啟用 cURL 自動解壓縮 HTTP 回應，並評估是否關閉。
