North Korea-Linked PolinRider Poisons Over 7,600 GitHub Repositories to Spread Malware

📰 The Hacker News · The Hacker News · 2026-11-26

報導指出，PolinRider 攻擊行動被觀察到在 GitHub 儲存庫中植入 Python 載入器，有跡象顯示該活動最早可能始於 2025 年 2 月。標題稱受影響儲存庫超過 7,600 個，並與北韓有關聯。

依 SafeDep 報告，載入器藏在小型 utils 套件或 conftest.py 中，當 Python 匯入該檔案時會讀取最新的交易資料（來源片段在此處截斷）。完整感染鏈與 IOC 未於提供內容中列出。

🔔 建議行動
  • 檢查程式庫與依賴中的 conftest.py 及小型 utils 套件，留意異常的網路請求或編碼載入程式碼。
  • 查閱 SafeDep 原始報告取得 IOC，並與內部儲存庫、CI 紀錄比對。
  • 在採用外部儲存庫程式碼前進行審查，並於隔離環境執行測試。
