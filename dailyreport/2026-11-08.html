Claude Code's “Don't Ask Again” File Exposes Passwords and Keys in 1,122 Public Copies on GitHub

📰 The Hacker News · The Hacker News · 2026-11-07

報導指出，開發者在 Claude Code 中核准的指令若內含密碼或 API 金鑰，這些機敏資訊目前出現在公開的 GitHub 儲存庫中，任何人都能讀取。

依來源描述，當使用者選擇「Yes, and don't ask again」時，該 AI 編碼助理可能將指令原文（包含其中的機密）存入專案設定檔。資安公司 Apiiro 表示發現 1,122 個公開副本。來源摘要內容被截斷，其餘細節（受影響範圍、是否已有修補或官方回應、是否有實際濫用）無法由所提供資料確認。

🔔 建議行動
  • 檢查團隊儲存庫中 Claude Code 的專案設定檔，確認是否含有曾核准指令中的密碼、API 金鑰或權杖，並避免將該設定檔提交到公開儲存庫。
  • 若發現機密已出現在公開儲存庫，立即撤銷並輪替相關憑證，再評估是否需清理版本歷史。
  • 避免在指令中直接內嵌機密，改用環境變數或機密管理工具，並在 CI 或 pre-commit 加入機密掃描。
