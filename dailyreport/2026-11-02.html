CVSS 10.0 LXD, MicroCloud Flaw Lets Attackers Impersonate Trusted Clients Without a Private Key

📰 The Hacker News · The Hacker News · 2026-11-01

來源報導指出,Canonical 的 LXD 與 MicroCloud 存在嚴重漏洞,攻擊者可在不持有受信任用戶端私鑰的情況下,冒充該受信任用戶端登入。標題標示 CVSS 為 10.0,但提供的內容並未列出對應的 CVE 編號,也未提供 CVSS 向量。

利用條件依來源描述為:攻擊者須能透過網路連到 LXD 的 HTTPS API,且已取得受信任用戶端的公開憑證。成功後可以該用戶端身分存取叢集及其虛擬機。來源摘要在此處中斷,受影響版本、修補版本與實際利用情形均未提供,無法確認。

🔔 建議行動
  • 盤點環境中的 LXD 與 MicroCloud 執行個體,並查閱 Canonical 官方公告確認受影響與已修補版本後儘速更新。
  • 限制 LXD HTTPS API 的網路暴露範圍,僅允許管理網段或必要來源存取。
  • 檢視受信任用戶端憑證清單與近期 API 存取紀錄,移除不再使用的憑證。
