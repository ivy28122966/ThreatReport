CVE-2026-80092 Microsoft Identity Web Elevation of Privilege Vulnerability

📰 Microsoft Security Response Center · Microsoft · 2026-10-19

Microsoft 更新了 Microsoft Identity Web 權限提升漏洞 CVE-2026-80092 的公告，把 v3 與 v4 分開列在安全更新表中，並釐清受影響的版本範圍。對應的安全更新版本分別為 3.16.0 與 4.16.1。

Microsoft 表示這次更新只是資訊性變更，修補內容本身沒有改變。來源資料沒有提供 CVSS 分數、利用狀態或受影響版本的具體區間，因此無法據此判斷嚴重程度；此處標為 info，代表資料不足，並不表示這是低風險漏洞。

🔔 建議行動
  • 盤點使用 Microsoft Identity Web 的應用程式，確認目前使用的是 v3 還是 v4 套件。
  • 確認 v3 已升級到 3.16.0 以上、v4 已升級到 4.16.1 以上。
  • 到 MSRC 公告頁查看更新後的受影響版本範圍與嚴重性評級。
