New SignDrop Zero-Day Exploit Turns Windows CLFS Security Feature Into SYSTEM Access

📰 The Hacker News · The Hacker News · 2026-11-12

本週稍早公開的 PoC「SignDrop」宣稱，本機 Windows 使用者可透過 Common Log File System（CLFS）驅動程式取得 SYSTEM 權限。

該 PoC 針對去年新增的日誌驗證功能。當高權限程序開啟特製日誌時，它利用 clfs.sys 建立附屬檔案的方式，以路徑重新導向取得控制。來源摘要未提供 CVE、CVSS、KEV 或修補資訊，風險等級依其公開 PoC 與 SYSTEM 提權描述暫列 high。

🔔 建議行動
  • 追蹤 Microsoft 的官方公告與修補，一旦釋出就優先部署。
  • 在修補前，強化對 clfs.sys 異常行為與本機提權跡象的監控，並限制不受信任使用者的本機登入。

CRITICAL 其他容器登錄庫Red Hat Quay

Critical Red Hat Quay Flaw Lets Attackers Read and Overwrite All Private Container Images in a Registry

📰 The Hacker News · The Hacker News · 2026-11-12

Red Hat Quay 的嚴重漏洞，可讓能存取 Quay 登錄庫的攻擊者讀取並覆寫每個儲存庫中的私有容器映像。

Quay 預設啟用匿名存取，啟用時攻擊者不需帳號。關閉匿名存取後，任何有效帳號仍可利用。Red Hat 已發布多個 Quay 版本的修正版本；摘要沒有提供 CVE 或 CVSS。

🔔 建議行動
  • 依 Red Hat 公告確認所用 Quay 版本，並盡速升級到修正版本。
  • 在修補前，檢查是否啟用匿名存取，並限制登錄庫的網路可達範圍。
  • 檢視映像摘要與推送紀錄，確認私有映像沒有遭到非預期覆寫。
