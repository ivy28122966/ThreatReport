Attacker Used 4,837 Hijacked GitHub Accounts to Run a CI Secret Stealer in 1,806+ Repositories

📰 The Hacker News · The Hacker News · 2026-11-12

依 Aikido Security 的說法，攻擊者自週二起利用 4,837 個 GitHub 帳號的被竊憑證，在這些帳號可寫入的儲存庫中植入密鑰竊取程式，目標是 CI 工作流程可存取的密鑰與雲端憑證。

該程式至少在 1,806 個儲存庫中執行，攻擊者可能已取得相關機密（來源用語為「likely」）。

🔔 建議行動
  • 檢查近期 CI 工作流程檔與提交紀錄是否有未預期的變更，並盤點受影響儲存庫。
  • 對 CI 可存取的密鑰與雲端憑證進行輪換，並啟用多因素驗證、審視帳號與 token 權限。

CRITICAL 其他ApacheRCE

Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely

📰 The Hacker News · The Hacker News · 2026-11-12

Apache HTTP Server 的 mod_http2 模組存在嚴重漏洞（CVE-2026-119618），遠端攻擊者可能在伺服器上執行程式碼。影響 2.4.55 至 2.4.70 版，已於 2.4.71 修復。

依 Red Hat 說明，僅啟用 HTTP/2 的伺服器受影響。來源未提供 CVSS 與 KEV 狀態，亦未說明已有利用活動。

🔔 建議行動
  • 盤點 Apache HTTP Server 版本，將 2.4.55–2.4.70 升級至 2.4.71 或廠商提供的修補版本。
  • 無法立即升級時，評估是否暫時停用 HTTP/2（mod_http2），並限縮對外暴露。
