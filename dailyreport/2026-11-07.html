CVE-2026-83844 Windows Paint Remote Code Execution Vulnerability

📰 Microsoft Security Response Center · Microsoft · 2026-11-06

Microsoft 針對 CVE-2026-83844（Windows Paint 遠端程式碼執行漏洞）釋出新版 Paint，組建版本為 11.2609.401.0。Microsoft 建議安裝此新版，或確認應用程式已自動更新。

來源摘要未提供 CVSS 分數、嚴重度評級或利用狀態，沒有足夠資料驗證風險，故暫列為 info；這不代表低風險。

🔔 建議行動
  • 確認端點上的 Paint 版本已更新至 11.2609.401.0 或更新版本。
  • 核對 Microsoft Store 自動更新是否在受管環境中被停用或延遲。

HIGH 漏洞與修補CISA KEVSonicWallMFA 繞過

CVE-2026-19868 — SonicWall SonicOS SSLVPN Use of Single-factor Authentication Vulnerability

📰 CISA Known Exploited Vulnerabilities Catalog · CISA · 2026-11-06

CISA KEV 收錄 SonicWall SonicOS SSLVPN 的單因素驗證使用漏洞（CVE-2026-19868）。持有替代驗證方式有效憑證的使用者，可能繞過 SAML 驗證控制，進而繞過 SAML 強制的多因素驗證（MFA）。

CISA 要求依廠商指示套用緩解措施，並遵循 BOD 26-04 與「Forensics Triage Requirements」；若無緩解措施可用，應停止使用該產品。來源未提供 CVSS 分數。

🔔 建議行動
  • 盤點所有啟用 SAML 驗證的 SonicOS SSLVPN 設備，依廠商指示套用緩解措施。
  • 依 CISA 要求評估資產的網際網路暴露情形，並進行必要的鑑識分流檢查。
  • 若暫無可用緩解措施，評估依 CISA 指引停用該服務。

Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot

📰 The Hacker News · The Hacker News · 2026-11-06

Previdian 指出，攻擊者正嘗試利用 OpenSSH 漏洞 CVE-2026-123158（代號 SSHole，CVSS 8.1），可登入未設定密碼的帳號。受影響的是在 musl C library 上執行 OpenSSH 且停用 PAM 的 Linux 系統。標題指出攻擊者在 honeypot 上取得 root。

  • 檢視 SSH 登入紀錄中是否有異常的無密碼登入。
