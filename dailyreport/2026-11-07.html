Hackers Hide Linux Backdoor in Control Web Panel Server to Execute Commands Without Logs

📰 The Hacker News · The Hacker News · 2026-11-06

QiAnXin XLab 研究人員指出，在執行 Control Web Panel（CWP，免費的 Linux 主機管理面板）的網頁伺服器中發現後門。該後門會執行攻擊者經由網頁請求傳送的指令，且這些請求不會出現在存取日誌中。

植入後門需要 root 權限，代表攻擊者必須已控制該伺服器，因此它屬於入侵後的持久化與隱匿手段，而非初始入侵漏洞。來源摘要未提供 CVE、CVSS 或 IOC。

🔔 建議行動
  • 盤點使用 CWP 的主機，比對網頁伺服器二進位檔的完整性與來源。
  • 不能只依賴存取日誌，另以主機行為、行程與網路連線監控補強偵測。
  • 若懷疑已遭入侵，應視為 root 已失陷，進行鑑識並評估重建主機。
